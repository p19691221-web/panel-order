# 板件加工單

給系統櫃店家與板材加工廠用的拆單工具：拆櫃體、檢查常見錯誤、估算排板張數，產出可列印的加工單。單一網頁，不需安裝，資料只存在自己的裝置。

## 功能

- **快速拆櫃體**：輸入寬、高、深、板厚、層板數、門片數，自動拆出側板、頂底板、層板、背板、門片（含封邊與紋路）。
- **板件表**：可手動新增、修改，每片記錄長、寬、厚、數量、板材、紋路方向與四邊封邊。
- **自動檢查**：未指定板材、尺寸超過原板（含修邊與紋路限制）、小於最小加工尺寸、長寬可能填反、薄板封邊、重複列、同板材不同厚度、未填交期等。
- **排板估算**：依板材與厚度分組，估算原板張數、利用率，並畫出每張板的擺放示意。
- **交付**：列印／存成 PDF（含店家與加工廠簽名欄）、匯出 CSV（Excel 可開）、存成檔案給對方讀取。

## 限制

- 拆櫃規則為簡易假設（側板包頂底、背板外釘、門片蓋柱、層板退縮 20 mm）；各家做法不同，拆完要核對。
- 排板是簡易的整排擺放，只用來估算，實際排板以加工廠軟體為準。
- 沒有孔位、五金、溝槽資料；不連接 CNC 機台。
- 原型，尚未經實際加工廠使用驗證。
